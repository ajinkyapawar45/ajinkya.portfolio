HOW TO PUBLISH FREE USING GITHUB PAGES:
1. Sign in to GitHub or create an account at https://github.com.
2. Create a new public repository, for example: ajinkya-portfolio.
3. Upload index.html to the repository's root (top-level) folder.
4. Open the repository's Settings, then Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for the Pages deployment to finish. The public site URL will appear in Settings > Pages, usually in the form:
   https://YOUR-USERNAME.github.io/ajinkya-portfolio/
8. Open that URL on your phone to test it. You can then add it to your resume and LinkedIn.

Alternative:
Netlify also supports publishing a static site by uploading the website folder through its deploy interface. Follow its current on-screen instructions at https://www.netlify.com/.
